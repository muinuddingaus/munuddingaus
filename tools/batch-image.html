ChatGPT Batch Image Enhancer

Process a group of images through ChatGPT with one shared prompt, one image per chat.

Chrome extension

What it does

Select multiple images, enter one prompt, and let the extension move through them sequentially. It opens ChatGPT, uploads an image, waits before sending, sends the prompt, waits for the result, then starts a new chat for the next image.

Open ChatGPTRequest download link

Current workflow

  • Select multiple images
  • Write the prompt once
  • 5-second wait before Send
  • 20-second wait after Send
  • New Chat opens for the next image
  • Pause, resume and stop are supported

How to use

1. Select images

Choose the images you want to process from your computer.

2. Write one prompt

Use the same instruction for every selected image.

3. Start

The extension works through the images sequentially with the built-in delays.

4. Review

Review the generated results in ChatGPT as each image is processed.
